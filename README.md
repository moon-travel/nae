# スクワットフォーム研究室

PC・スマートフォンのブラウザで、正面から見たスクワットの動きを測定する研究用プロトタイプです。MediaPipe Pose Landmarker Full の33点ランドマークから、立位キャリブレーション、スクワットの4状態、rep数、深度・体幹傾斜・左右差を計算します。日本語の音声フィードバックは画面で切り替えられます。

## 起動

Node.js 20.19以降または22.12以降を用意し、次を実行します。

```bash
npm install
npm run assets
npm run dev
```

表示された `http://localhost:5173/` を開き、カメラを許可します。画面に全身を映して正面を向くと、画角と品質が安定するまで待ってから立位キャリブレーションが自動で始まります。自然に立ったまま安定した複数フレームが得られると、自動的に計測を開始します。途中で全身が見えなくなると安定待ちや立位測定はやり直されるため、所要時間は変わります。自動計測終了後は再アームされないため、画面の再セット操作で次の計測を開始してください。「終了して保存」でセッションを閉じます。計測終了後も再測定しやすいようカメラのプレビューは続き、ページを閉じるとカメラを停止します。研究モードは画面上のスイッチ、または `?research` で有効にできます。研究モードで開始したセッションのみ、推論フレームごとの解析済み指標を記録します。

音声はブラウザのユーザー操作制限により、自動計測開始だけでは有効になりません。必要ならカメラから離れる前に「音声を有効にする」を押してください。音声の有無は自動計測を妨げません。日本語音声の種類は端末とブラウザに依存します。

```bash
npm run typecheck
npm run test
npm run build
```

Pose Landmarker Fullモデルは `public/models/pose_landmarker_full.task` に含めています。`npm run dev` と `npm run build` は事前に `npm run assets` を実行し、インストール済み `@mediapipe/tasks-vision` からWASMを `public/models/mediapipe/` にコピーします。モデルがない場合のみ、セットアップスクリプトが公式配布元から取得します。Vercelでも `npm run build` を実行すれば、モデルとWASMが `dist/models/` に含まれます。実行時はこれらのローカル配信アセットを使い、有料APIは使いません。本番でカメラを使うにはHTTPSが必要です。localhostはブラウザのsecure contextとして扱われます。

## 構成とデータ

カメラフレームは原則Web Workerへ転送し、`VIDEO`モードのPose Landmarkerで処理します。Workerが起動・推論できない環境ではメインスレッド版に切り替えます。推論待ちのフレームはキューに積まず間引きます。鏡表示はvideo/canvasの表示だけに適用し、解析ランドマークの左右は変更しません。

`src/pose/` はMediaPipe推論、`src/squat/` と `src/filters/` は品質確認・平滑化・キャリブレーション・状態機械・数値計算、`src/feedback/` は数値からの候補判定と音声、`src/storage/` はIndexedDB保存を担当します。測定とフォーム判定は分離しています。

カメラ映像はサーバーへ送信せず、動画も保存しません。ブラウザ内のIndexedDB `squat-research` に保存するのは、匿名参加者ID（任意）、キャリブレーション、repごとの集約値、研究モードでの解析済みmetricsだけです。CSVも使用しません。ブラウザのサイトデータを削除すると記録も消えます。

## 現在の制限

このシステムは研究用プロトタイプです。MediaPipe world landmarksから計算する3D膝角度は推定値であり、モーションキャプチャによる真値ではありません。フォーム判定の閾値は実験前の暫定値で、`src/squat/analysisConfig.ts` と `src/feedback/feedbackConfig.ts` にまとめています。医学的な診断、傷害予測、個人への運動処方を目的としません。正面姿勢の推定は左右ランドマークの奥行き差による簡易的なヒントで、照明・遮蔽・服装・カメラ位置による誤判定があり得ます。フィードバックは体幹・骨盤の大きな左右偏位に限定し、膝左右差の音声は初期状態で無効です。

フルモデルは端末性能によって推論FPSが変わります。音声の日本語voiceは端末・ブラウザに依存します。ブラウザのカメラ許可、IndexedDB、SpeechSynthesisが制限されている環境では該当機能が利用できません。閾値は実参加者の撮影条件で検証・調整が必要です。

開発環境ではカメラ映像からWorker推論が動き、姿勢品質ガイド・研究モードのFPSと遅延表示を確認しました。全身が入る画角での実スクワット、骨格の実測位置合わせ、実際の日本語音声、および異なるスマートフォンでのカメラと保存動作は、今後の実機検証項目です。合成ランドマークと模擬IndexedDBによる自動テストは、これらの実機検証を代替しません。
